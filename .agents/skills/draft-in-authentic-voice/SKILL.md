# Draft in an authentic voice

Create a paste-ready first draft that sounds owned by its author, not optimized by a generic writing assistant.

## Establish the voice

1. Gather the intent, audience, channel, source facts, constraints, and any approved writing samples already available.
2. If examples exist, read [references/voice-modeling.md](references/voice-modeling.md) and infer the smallest useful voice model. Prefer repeated evidence across examples over a single memorable phrase.
3. If examples do not exist, preserve the diction, directness, and cadence in the user's request. Ask for a sample only when matching an established voice is central and guessing would materially change the result.
4. Apply this priority when signals conflict: current task instructions, factual source material, approved examples, stated style preferences, then plain-language defaults.

## Draft from meaning first

- Decide the one outcome the writing should create and lead with the most useful point.
- Use concrete nouns, active verbs, and details from the source material. Never invent anecdotes, numbers, quotes, credentials, or consensus to make the writing feel authoritative.
- Match the channel. A text message, executive update, customer email, and public post should not share one default structure.
- Preserve uncertainty and limitations when they matter. Voice is not permission to overstate evidence.
- Keep authorship honest. Match the user's own voice or an authorized organizational voice; do not fabricate another person's endorsement or personal experience.

## Run the human-voice pass

- Remove generic preambles, praise, summaries of the prompt, and conclusions that merely restate the opening.
- Cut corporate filler, empty intensifiers, placeholder transitions, and sentences that could fit any author or topic.
- Break repetitive cadence. Vary sentence length because the idea calls for it, not to manufacture informality.
- Use headings and bullets only when they make the requested artifact easier to use.
- Treat familiar AI-associated words and sentence patterns as review signals, not forbidden tokens. Keep a phrase when it is precise, natural for the author, and better than the alternatives.
- Preserve intentional rough edges, contractions, humor, regional language, and fragments when the examples support them and readability remains intact.

## Deliver

Return the complete draft first. Do not preface it with an explanation. Add notes only when the user asks for rationale, a factual uncertainty needs resolution, or an alternate tone would create a meaningful choice.
