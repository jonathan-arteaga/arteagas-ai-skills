# Native Apple references

Start from Apple's own guidance. Add one visual archive only when examples would change the direction.

## Primary sources

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) — behavior, layout, navigation, accessibility, materials, motion, and writing.
- [Apple Design Resources](https://developer.apple.com/design/resources/) — current templates, system fonts, Icon Composer, and platform kits.
- [SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols) — symbols, variants, weights, rendering, animation, and limits.

## Selection

- New screen or flow: the matching HIG pattern plus Apple Design Resources.
- Type: Apple typography guidance and system text styles. Keep Dynamic Type.
- Interface icons: SF Symbols when the concept exists and the target OS supports it.
- App icon or product mark: Apple app-icon guidance and Icon Composer. Do not put SF Symbols in an app icon, logo, or trademark.
- Competitive screens: [Refero](https://refero.design/) only as the optional third source. Extract patterns; do not copy a screen.

## Constraints to report

Minimum OS, how navigation is presented, Dynamic Type, VoiceOver, whether a symbol exists in the target set, and whether an asset is system-provided or custom.
