# Brand, logo, and typography references

Use identity archives to analyze. Use type libraries only for lawful implementation. Inspiration is not a license to imitate.

## Identity analysis

- [Brand New](https://www.underconsideration.com/brandnew/) — recent identity launches, before-and-after systems, and critique.
- [BP&O](https://bpando.org/) — branding and packaging case studies.
- [LogoArchive](https://www.logo-archive.org/) — researched modernist marks, sorted for analysis and education.

Extract strategy, geometry, proportion, responsiveness, type role, and system behavior. Never reproduce a mark, monogram, mascot, trade dress, or distinctive combination.

## Typography

- [Fonts In Use](https://fontsinuse.com/) — real pairings and applications.
- [Fontsource](https://fontsource.org/) — self-hostable open-source web fonts and packages.
- [Google Fonts](https://fonts.google.com/) — open-font discovery and family metadata.
- [Fontshare](https://www.fontshare.com/) — free families, each under its own license.

## License gate

Before recommending a family:

1. Name the exact family, weights, styles, and source.
2. Open that family's license. Do not infer it from the library homepage.
3. Confirm web use, app embedding, redistribution, modification, and commercial use as needed.
4. Prefer system fonts or verified OFL/open fonts when a paid license is not material.
5. Record attribution or notice requirements and whether self-hosting is allowed.

Do not claim trademark clearance, uniqueness, or registrability. Recommend a professional clearance search before a final mark goes public.
